# Reserve nations

Each country folder has a `<fifa-slug>_players.txt` input. New entries use a comment-only template; add at least one valid player row before automatic workflow discovery will process them. Reserve drafts show starter positions only; the website overview omits a nation until all 11 starters are available.

The folder list follows FIFA/Coca-Cola Men’s World Ranking, published 7 October 2026, ranks 101–211: https://inside.fifa.com/fifa-rankings/world-ranking/men
